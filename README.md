# FileNest

FileNest 是本地文件整理工具。默认使用网页版，界面沿用 `test/ui-preview.html` 的蓝橙渐变、玻璃侧栏与卡片布局。文件在本机处理，不上传到外部服务。

## 启动网页版

使用项目已指定的解释器，无需安装第三方运行依赖：

```powershell
& 'D:\anaconda\Anaconda3\envs\agent-dev\python.exe' main.py
```

随后在浏览器打开 http://127.0.0.1:8765 。服务仅监听本机回环地址，不提供局域网访问；在启动窗口按 Ctrl+C 停止服务。请勿同时启动桌面版和网页版，以免同时修改配置和历史。

旧桌面版仍可通过 `main.py --desktop` 启动。

## 使用流程

1. 填写来源目录的完整路径；多个来源用英文分号分隔。填写整理目标，按需启用子目录扫描。
2. 在规则管理中新增、编辑、启停、删除或上移规则；文件采用第一条命中的启用规则。规则支持类型、关键词、日期、大小、移动、复制和重命名。
3. 点击「扫描并预览」。检查目标路径、动作和匹配详情；来源文件此时不会被修改。
4. 选择可执行项目，点击「立即开始整理」并确认。可以停止后续任务，已完成项会保留记录。
5. 在历史页面检查逐文件成功、失败和撤销结果。移动及重命名可在状态未变化、原位置无冲突时撤销；复制不自动撤销。

配置变更后必须重新生成预览。扫描时自动保存当前配置，也可以点击「保存配置」或「保存偏好」。规则编辑弹窗保存后立即持久化；卡片上的启停、排序与删除在保存配置或重新扫描时持久化。

浏览器通过手动填写路径访问本机目录，不依赖上传文件或浏览器文件夹上传控件。未扫描时显示真实空状态，不使用示例文件假装整理成功。

默认不覆盖文件；同名采用跳过或预览时自动编号。移动仅支持同一磁盘，跨盘请选择复制。首版不跟随符号链接或 Windows 目录联接，排除整理目标与内部数据目录，避免循环整理。

## 结构与数据

- `web/`：网页布局和交互，参考模板保持在 `test/ui-preview.html`。
- `web_app.py`：本机 HTTP 服务、后台任务和接口适配。
- `filenest/`：扫描、规则、计划、执行、历史与撤销核心。
- `ui/`：保留的桌面界面。
- `.filenest/`：两种界面共用的配置和 SQLite 历史记录。

预览计划保存在服务端，只能执行一次；刷新配置或重启服务后需要重新预览。服务校验 Host、请求来源与会话令牌，不允许其他网站直接发起文件修改。

## 验证

```powershell
& 'D:\anaconda\Anaconda3\envs\agent-dev\python.exe' -m pytest -q
node --check web/app.js
```

测试只在项目内 `test/_tmp` 创建样例文件，覆盖核心文件安全以及网页预览、执行、重复请求、取消和撤销。
